### 3.1 Password Hashing — `app/core/security.py`

- [ ] `hash_password(plain: str) -> str`
- [ ] `verify_password(plain: str, hashed: str) -> bool`
- [ ] Never log passwords, never return hashes in API responses

---

### 3.2 JWT Tokens — `app/core/security.py`

- [ ] `create_access_token(user_id, role, email) -> str`
  - Payload: `{ "sub": user_id, "role": role, "email": email, "iat": now, "exp": now + 15min }`
  - Signed with `HS256` using `JWT_SECRET_KEY`
- [ ] `create_refresh_token() -> str`
  - Generate cryptographically random 64-byte token (`secrets.token_hex(64)`)
  - Hash it (SHA-256) before storing in `sessions` table
  - Return the raw token (sent to client as HTTP-only cookie)
- [ ] `decode_access_token(token: str) -> dict`
  - Verify signature, check expiry
  - Raise `HTTPException(401)` if invalid or expired
- [ ] `hash_token(token: str) -> str` — SHA-256 hash for storage

---

### 3.3 OTP — `app/core/security.py`

- [ ] `generate_otp() -> str` — 6-digit zero-padded random integer
- [ ] `hash_otp(otp: str) -> str` — SHA-256 hash
- [ ] Store in Redis: key = `otp:{user_id}`, value = hashed OTP, TTL = 5 minutes
- [ ] Also store attempt counter: key = `otp_attempts:{user_id}`, TTL = 5 minutes
- [ ] `verify_otp(user_id, otp) -> bool`:
  - Increment attempt counter
  - If attempts > 3 → raise `HTTPException(429, "Max attempts exceeded")`
  - Compare hash(otp) with stored hash
  - On success → delete both Redis keys

---

### 3.4 AES-256-GCM Field Encryption — `app/core/encryption.py`

- [ ] `encrypt_field(plaintext: str) -> str`
  - Generate random 12-byte nonce
  - Encrypt with AES-256-GCM using `FIELD_ENCRYPTION_KEY`
  - Return base64-encoded `nonce + ciphertext + tag`
- [ ] `decrypt_field(ciphertext: str) -> str`
  - Decode base64
  - Extract nonce (first 12 bytes), tag (last 16 bytes), ciphertext (middle)
  - Decrypt and return plaintext
- [ ] Apply to: `diagnosis_notes`, `treatment_recommendations`, `audit_log.details`
- [ ] **Use SQLAlchemy TypeDecorator** to auto-encrypt/decrypt on read/write

```python
class EncryptedText(TypeDecorator):
    impl = Text
    cache_ok = True

    def process_bind_param(self, value, dialect):
        if value is not None:
            return encrypt_field(value)
        return value

    def process_result_value(self, value, dialect):
        if value is not None:
            return decrypt_field(value)
        return value
```

def require_roles(*allowed_roles: Role):
    async def check(current_user = Depends(get_current_user)):
        if current_user.role not in allowed_roles:
            raise HTTPException(403, "Insufficient permissions")
        return current_user

### 4.1 Auth Routes — `app/api/v1/auth.py`

#### `POST /api/v1/auth/login`
- [ ] Body: `{ email, password }`
- [ ] Look up user by email
- [ ] Verify password with Argon2
- [ ] Check user status:
  - `Inactive` → 403 "Account deactivated"
  - `Locked` → 403 "Account locked — contact admin"
- [ ] Track login failures in Redis: `login_attempts:{email}`
  - 3 attempts → 1 min lockout
  - 5 attempts → 15 min lockout
  - 10 attempts → lock account in DB + audit log
- [ ] On success:
  - Generate OTP, hash and store in Redis (5 min TTL)
  - Send OTP via email (background task)
  - Audit log: `LOGIN_SUCCESS`
  - Return: `{ message: "OTP sent to email" }` — do NOT return tokens yet
- [ ] On failure: audit log `LOGIN_FAILURE`, return generic "Invalid credentials"

#### `POST /api/v1/auth/verify-otp`
- [ ] Body: `{ user_id, otp }`
- [ ] Verify OTP (check hash, check attempts, check TTL)
- [ ] On success:
  - Create access token (15 min)
  - Create refresh token → hash and store in `sessions` table
  - Set refresh token as HTTP-only cookie (`Secure`, `SameSite=Strict`)
  - Update `user.last_login`
  - Audit log: `OTP_VERIFIED`
  - Return: `{ access_token, token_type: "bearer", user: { id, name, role, email } }`
- [ ] On failure: audit log `OTP_FAILED`, return 401

#### `POST /api/v1/auth/refresh`
- [ ] Read refresh token from HTTP-only cookie
- [ ] Hash it and look up in `sessions` table
- [ ] Check `expires_at` not passed
- [ ] Verify associated user is still `Active`
- [ ] Issue new access token
- [ ] Rotate refresh token (delete old session, create new one)
- [ ] Return: `{ access_token }`

#### `POST /api/v1/auth/logout`
- [ ] Requires: valid access token
- [ ] Delete session record from `sessions` table (by token hash from cookie)
- [ ] Clear Redis cache for user
- [ ] Clear refresh token cookie (set empty cookie with past expiry)
- [ ] Audit log: `LOGOUT`
- [ ] Return: `{ message: "Logged out" }`

#### `POST /api/v1/auth/resend-otp`
- [ ] Body: `{ user_id }` (or derive from temp token)
- [ ] Rate limit: max 3 resends per 10 minutes
- [ ] Generate new OTP → delete old one from Redis → store new one
- [ ] Send email (background task)
- [ ] Return: `{ message: "New OTP sent" }`

#### `POST /api/v1/auth/forgot-password`
- [ ] Body: `{ email }`
- [ ] Always return same response whether email exists or not (prevent enumeration)
- [ ] If email exists: generate reset token → store hash in Redis (30 min TTL) → send email

#### `POST /api/v1/auth/reset-password`
- [ ] Body: `{ token, new_password }`
- [ ] Validate token from Redis
- [ ] Enforce password complexity: min 12 chars, uppercase, lowercase, digit, special char
- [ ] Hash new password → update user record
- [ ] Invalidate all active sessions for user
- [ ] Return: `{ message: "Password updated" }`

## 🤖 Phase 5 — AI Inference Service

> This is a **separate microservice** (`ai_service/`). Runs in its own Docker container with GPU access.

### 5.1 AI Service FastAPI App — `ai_service/main.py`

- [ ] Separate FastAPI app (not the main backend)
- [ ] Single endpoint: `POST /predict`
- [ ] Auth: internal API key (`X-Internal-API-Key` header) — only main backend can call it
- [ ] Load YOLOx model on startup (not per-request)
- [ ] Return predictions within ≤ 12 seconds or return 504 timeout

---

### 5.2 Image Preprocessor — `ai_service/model/preprocessor.py`

- [ ] `preprocess(image_bytes: bytes, file_format: str) -> np.ndarray`
  - [ ] For DICOM: use `pydicom` to extract pixel array, convert to 8-bit grayscale
  - [ ] For PNG/JPEG: decode with OpenCV or Pillow
  - [ ] Convert to RGB (3 channels, even for grayscale X-rays)
  - [ ] **Apply CLAHE** (Contrast Limited Adaptive Histogram Equalization):
    ```python
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    img_clahe = clahe.apply(gray_channel)
    ```
  - [ ] Resize to `640 × 640` pixels (YOLOx input size)
  - [ ] Normalize pixel values: divide by 255.0 → range [0.0, 1.0]
  - [ ] Convert to tensor with shape `[1, 3, 640, 640]`

---

### 5.3 YOLOx Inference Engine — `ai_service/model/inference.py`

- [ ] Load model weights once at startup:
  ```python
  # Load YOLOx model
  model = get_exp(exp_file, exp_name).get_model()
  model.load_state_dict(torch.load(weights_path, map_location=device))
  model.eval()
  ```
- [ ] `run_inference(tensor) -> list[Prediction]`
  - Run forward pass: `with torch.no_grad(): outputs = model(tensor)`
  - Apply NMS (Non-Maximum Suppression) to filter overlapping boxes
  - Map class indices to disease names:
    - Class 0 → `Pneumonia`
    - Class 1 → `Tuberculosis`
    - Class 2 → `Lung_Tumor`
  - Convert bounding boxes from `[x_center, y_center, w, h]` (normalized) to `[x, y, w, h]` pixel coordinates (relative to 640×640)
  - Filter predictions with confidence < 0.1 (raw threshold — UI slider handles display filtering)
  - Return list of `{ disease_class, bounding_box: {x, y, w, h}, confidence_score }`
- [ ] Record `processing_time_sec` from start of preprocessing to end of inference
- [ ] Handle GPU out-of-memory: catch `torch.cuda.OutOfMemoryError` → retry on CPU → log warning

---

- [ ] **Dependency injection:** Never instantiate services inside routes — use FastAPI `Depends()`
- [ ] **Secrets:** All secrets in environment variables, loaded via `pydantic-settings` — never in code or committed to git
